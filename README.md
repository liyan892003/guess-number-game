# 🎯 猜数字游戏 - 课堂互动

一个用于活跃课堂气氛的在线互动猜数字游戏，支持100多人同时参与！

## 功能特性

- 🎲 随机生成1-100之间的整数
- 📊 实时提示猜大了/猜小了，并自动缩小范围
- 👥 **分组机制**：将玩家分成每组5人，轮流参与，确保每个同学都有机会
- 💬 实时聊天和猜题记录
- 🎨 美观的UI界面
- ⚡ WebSocket实时通信

## 分组设计思路

考虑到100多人同时参与，但一轮游戏只需要猜几次就能猜中，我们采用了**分组轮流**的机制：

1. **自动分组**：系统会自动将所有玩家分成每组5人的小组
2. **轮流参与**：每次只有一个小组的玩家可以猜数字
3. **公平轮换**：猜完一次后，自动轮到下一个小组
4. **灵活补位**：有新玩家加入时会自动重新分组

这样既能保证课堂参与度，又能让游戏有序进行！

## 安装和运行

### 1. 安装 Node.js

首先需要安装 Node.js，请访问 https://nodejs.org/ 下载并安装LTS版本。

### 2. 安装依赖

在项目目录下运行：

```bash
npm install
```

### 3. 启动服务器

```bash
npm start
```

### 4. 访问游戏

打开浏览器访问：http://localhost:3000

学生可以通过局域网IP地址访问，例如：http://192.168.x.x:3000

## 游戏流程

1. **加入游戏**：学生输入名字加入游戏
2. **自动分组**：系统自动将学生分成5人一组
3. **开始游戏**：老师点击"开始游戏"按钮
4. **轮流猜题**：当前小组的学生可以猜数字
5. **范围提示**：系统提示猜大了/猜小了，并缩小范围
6. **轮换小组**：猜完后自动轮到下一个小组
7. **胜利条件**：猜中数字的同学获胜！

## 文件说明

- `server.js` - 后端服务器，处理游戏逻辑和WebSocket通信
- `public/index.html` - 前端页面
- `public/style.css` - 样式文件
- `public/game.js` - 前端游戏逻辑
- `package.json` - 项目配置

## 技术栈

- **后端**：Node.js + Express
- **实时通信**：Socket.io
- **前端**：原生 HTML + CSS + JavaScript

## 自定义配置

如果需要修改每组人数，可以在 `server.js` 中修改：

```javascript
const GROUP_SIZE = 5; // 修改这个数字
```
